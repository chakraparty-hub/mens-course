# The Filter — Mens Course

**The 8-Week Coaching System for Successful Men to Stop Attracting the Wrong Woman — and Build a Relationship with the Right One.**

> Your problem was never attraction. It's filtration.

## Contents

| File | What it is |
|---|---|
| `index.html` | Landing page for the program (ready for GitHub Pages) |
| `The_Filter_Coach_Talk_Track.docx` | Full coaching program: 8 modules, talk tracks, exercises, coaching toolkit, marketing pack |

## The 8 Modules

1. **The Magnet Problem** — Why your success attracts the wrong woman
2. **The Standard of Five** — Know your worth, set your non-negotiables
3. **The 7 Warning Patterns** — Gold digger, controller, drama engine, fixer-upper, love bomber, status hunter, exit plan
4. **The 90-Day Vetting System** — Evidence, not chemistry
5. **The Partnership Matrix** — Character, energy, alignment, contribution, loyalty
6. **Boundaries & Protection** — Time, energy, money, peace
7. **The Decision Framework** — Head, heart, and gut
8. **Building It Right** — From the right woman to the right relationship

## Quick start

- Open `index.html` in any browser to preview the landing page.
- Upload `The_Filter_Coach_Talk_Track.docx` to your CRM / client portal as the program deliverable.
- To publish the landing page live: enable **GitHub Pages** for this repo (Settings → Pages → Deploy from branch `main`, root).
